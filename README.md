# Task Manager API

**Task Manager API** — это учебный проект, представляющий собой RESTful API для системы управления задачами, проектами, встречами и комментариями. Проект демонстрирует практическое применение современных подходов к разработке backend-приложений, включая работу с базами данных, транзакциями и сложными запросами.

**[Посмотреть отчет SonarCloud](https://sonarcloud.io/summary/overall?id=kless3_task-manager-uni&branch=main)**

## 🚀 Функциональность

API предоставляет полный набор эндпоинтов для управления следующими сущностями:

### 📁 Проекты (Projects)
- Получение списка всех проектов
- Получение проекта по ID
- Фильтрация проектов по статусу
- Создание, обновление и удаление проектов
- Расширенная фильтрация (по статусу, меткам, с учетом просроченных) через JPQL и нативные SQL-запросы

### ✅ Задачи (Tasks)
- Получение всех задач
- Получение задачи по ID и по названию
- Получение задач по проекту
- Создание, обновление и удаление задач
- Демонстрация работы с транзакциями (`withTx` и `woTx`)

### 💬 Комментарии (Comments)
- Получение комментария по ID
- Получение всех комментариев к задаче
- Создание, обновление и удаление комментариев

### 🏷️ Метки (Labels)
- Получение всех меток
- Получение метки по ID
- Создание, обновление и удаление меток для задач

### 📅 Встречи (Meetings)
- Получение всех встреч с пагинацией и сортировкой
- Получение встречи по ID
- Получение встреч по проекту
- Создание, обновление и удаление встреч
- Массовое создание встреч
